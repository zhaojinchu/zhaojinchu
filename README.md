# Zhaojin Chu

I'm an Electrical and Computer Engineering student at Carnegie Mellon, graduating in May 2028.
I'm also an undergraduate researcher at CMU's Microdynamic Systems Laboratory, where I replaced
the QNX PC running the servo loop of a 6-DOF magnetic levitation haptic device with an STM32H7
on FreeRTOS.

## Projects

- [ASICraft](https://github.com/zhaojinchu/ASICraft): compiles SystemVerilog into redstone
  circuits for vanilla Minecraft, written in Rust, with a browser playground at
  [redstonefab.zhaojinchu.com](https://redstonefab.zhaojinchu.com/).
- [ReBin](https://github.com/zhaojinchu/TartanHacks): won Best Hardware at TartanHacks 2026. A
  waste-sorting bin attachment that runs YOLOv8n on a Raspberry Pi 5, with ultrasonic fill
  sensors and a dashboard that predicts when each bin will be full.
- [TeleKart](https://github.com/zhaojinchu/TeleKart): an RC car driven over Wi-Fi from a Mac with
  a USB steering wheel, with live video from the Raspberry Pi Zero 2 W on the car.
- [Present](https://github.com/zhaojinchu/Present): a class attendance app built at HackCMU 2026
  with a team of four, where friends post a photo from the room as each class starts.
- [Logic Labs storefront](https://github.com/zhaojinchu/LogicLabsCommercePlatform): the online
  shop for Logic Labs' electronics kits, in React with Supabase and Stripe Checkout.
