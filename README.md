# Zhaojin Chu

I'm an Electrical and Computer Engineering student at Carnegie Mellon, graduating in May 2028,
and an undergraduate researcher at CMU's Microdynamic Systems Laboratory. At the lab I replaced
the QNX PC running the servo loop of a 6-DOF magnetic levitation haptic device with an STM32H7
on FreeRTOS, and hand-routed the interface board that goes with it.

Lately I've been building [ASICraft](https://github.com/zhaojinchu/ASICraft), which compiles
SystemVerilog into redstone circuits for vanilla Minecraft. You can try it at
[redstonefab.zhaojinchu.com](https://redstonefab.zhaojinchu.com/). My other projects are pinned
below.
